# 管理员注册许可与持久审计

状态：已决定；实现和运行证据由 #2347 产品 PR 绑定受测 HEAD。本文不代表 T3 完成。

Identity SDK 的 VerifiedIdentity 仍是唯一可信管理员事实，每请求在线复核；Policy 独立检查当前静态角色与设备范围。新增注册权限必须显式配置，变更重启生效。本期只允许管理员签发、撤销和消费本人许可，形成持久注册申请；设备端入口、DevicePrincipal/证书归 #2348/I01/F04，申请目标 ID 不是设备身份证明。

应用内部 enrollment 定义闭合操作，access 产生私有请求权限，access_store 独占事务，audit 定义脱敏事件。不存在新公共 crate、通用幂等框架、ledger、Outbox 或无审计运行模式。许可固定 enrollment 用途、300 秒、单次；状态为 available/consumed/revoked，期限由数据库时钟在取得锁后检查。

mdm_api 保持 Inventory 只读；新增 mdm_access 登录角色和独立池，只有 access schema 的必要读写权限。两池连接同一产品数据库，各由生命周期作用域接管并有界关闭。操作、许可/申请和成功审计使用同一连接、同一 PG 事务；数据库迁移继续由 mdm_owner 单一执行。既有迁移摘要不可改，新单元追加安装。

每个写请求使用 UUID Idempotency-Key。tenant/actor/key 定义恢复身份，client、操作种类、规范业务字段摘要约束重放；同键异内容冲突。事务锁串行相同操作，许可行锁串行消费。成功回执是原操作结果，不是许可当前状态；签发回执状态 issued 不承诺许可仍有效。提交未知后重发原请求，只返回原回执，不重复扣次、申请或成功审计；恢复前仍需当前身份和资源权限，已消费状态不会阻止恢复原成功结果。原键不能因为超时或过期而更换。

查询与非事务响应由 envelope 完成持久审计后释放数据。总请求处理预算为 8 秒，额外预留 2 秒审计收尾；写事务成功已携带审计，不再次记录成功。重试记录 replay，身份拒绝不自报 actor；无法辨认的主体记 unknown。提交不确定或取消不伪记业务失败，查询/拒绝审计失败返回 503 并告警。客户端取消导致请求 future 被销毁时，以 audit_failure 运维事件暴露未完成收尾，不宣称该请求已产生持久审计。运维日志不替代业务审计。

配置与应用构造接口直接更新，所有调用方同时迁移，不支持缺字段默认回退。审计事件不保存凭据、token、Cookie、请求原文或任意 provider 错误；运行角色不能更新/删除审计，无自动保留清理。访问和保留由产品部署 owner 管理，不宣称防 DBA 篡改、WORM 或已完成审计 UI。

验证：T1 覆盖配置、操作身份与参数；真实 PG T2 覆盖最小权限、隔离、并发、审计故障回滚、COMMIT 前失败及真实提交后确认丢失恢复；真实 Identity 候选测试覆盖管理 HTTP 接线和失效。完整本地 make ci 绑定已提交 HEAD，T1/T2 不代替设备 T3。
