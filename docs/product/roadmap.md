# 工程路线

本文件只描述依赖与交付结果；需求及 R0–R3 发布门由 [PRD](rss-mdm-prd.md) 持有，进度由 tracker 持有。

| 波次 | 前置与结果 |
| --- | --- |
| 身份与资产基础 | 公共持久机制 → 管理员认证/授权 → 通道中立注册、可信报告、Inventory。报告 durable、投影完成与查询授权分别可核实。 |
| 原生只读纵切 | 身份基础 + Windows 协议 → 注册证书、认证 SyncML、CollectionRun、授权资产 API → 真机 T3。注册成功不代替查询闭环。 |
| 后端管理 | 组/范围/策略与资源/软件源核心可并行；各自持久化后，由应用组装引用、权限、审计及计划/发布。无需等待终端验收。 |
| 可信执行 | 命令事务与不可变资源 → 批准、能力预检、下发/回执/恢复 → 原生配置与 Agent 动作；状态、进度和效果分别验证。 |
| Agent 与 Apple | 共享 wire 先于独立 Agent 消费；Agent 公共 journal 先于 Windows/macOS adapter。Apple 原生依赖组织证书、APNs 与设备，Agent-only 不依赖原生注册。 |
| 企业闭环 | 可信执行 + 平台能力 → 三类采集、软件安装/撤回、更新及安全能力；WinGet/Brew 终端消费需要真实 Agent，后端发布可提前完成。 |
| 迁移与退出 | 按设备群承诺能力冻结身份映射、停写、未知任务处置与恢复 → 单一控制 owner 接管 → 自有旧实现退出。 |

通道中立身份完成后，Windows、Apple 与 Agent 按各自依赖并行；ADE 不依赖 WinGet，更新环不依赖凭据托管。共享装配文件由同一集成人串行修改，跨仓任务分别交付 PR。

每个产品闭环冻结 OS/build/edition、注册方式、权限、依赖和故障范围。缺真实设备只能证明服务端接缝；工程波次不降低 PRD 发布门。现有部署与前端基线必须实地盘点，历史 ZIP 不证明生产状态。
