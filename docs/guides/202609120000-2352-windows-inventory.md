# Windows 资产采集与查询

#2352/#2353 在已有 Windows 管理通道中采集设备型号与系统版本。每个完成双向 SyncML 认证的新会话创建一个 CollectionRun；没有手工重采、调度、历史列表或 Agent 入口。

## 采集与恢复

| Get URI | Inventory 字段 |
| --- | --- |
| ./DevInfo/Mod | device.model |
| ./DevDetail/SwV | device.os.version |

Inventory 核心唯一持有字段键和 UTF-8 值规则；Windows adapter 以穷举映射绑定 URI，命令数量、CmdID 范围、累计字段槽和完整性判定从同一目录派生。型号与版本均需非空、最多 256 个 Unicode 标量且不含控制字符；完整请求另受字节预算约束。非法值仅保存诊断摘要，不能通过长输入放大持久记录。

管理会话按 challenge、collecting、complete 推进，延续最多 8 条消息与 15 分钟窗口。Get 的 MsgRef、CmdRef、URI 必须精确关联已保存的请求；字段可以分消息返回。Final 表示该消息结束，不能证明完整采集。每个字段均得到成功 Status 加有效 Results，或明确的 501（未实现）结果时，才封存 Snapshot；501 持久化为 Unsupported 并保留 lastKnown。404、500、缺失或超时不推断不支持；包含这些非完整结果时，有已报告结果为 Partial，无已报告结果为 Failed。Partial/Failed 不覆盖既有资产。没有设备字段响应的纯超时仅终结 run，不制造 Observation 报告。

每个会话实例使用独立 UUID 作为 run/batch ID，sequence 在同 Scope 内递增。Get CmdID 在 registration/source epoch 内递增且不回绕，SessionID 清理后重用也无法关联旧结果。相同消息只重放已提交响应，同号不同内容返回冲突。接受片段时在事务内按 registration、credential、source 顺序复核授权，片段、协议状态、精确响应与审计一起提交。

终结时冻结 Scope、batch ID、sequence、规范字节、指纹和时间。数据时间基于服务器实际收到字段响应的时间；finished_at 单独表示终结时间，超时不会把旧字段伪装成此刻采集。设备未声明可信测量时间。

CollectionRun 自身是持久接入记录。后台仅恢复其中已封存的原报告，并交给 RSS Observation 的 activate/receive；不另建报告队列。后续吊销或换代拒绝新输入，已接受的历史输入可以终结封存并恢复至原 Scope。恢复入口统一验证关系行的 tenant、registration、source、epoch 与封存 Scope 一致，并验证 Inventory dataset、batch 与指纹。该授权不能创建任意 batch，也不能变更内容。提交未知保留原报告；lookup 未找到不能证明回滚。

Observation 独占 receipt、重放冲突与 journal。应用直接组合 PgSource、既有 Inventory PgEffect 和 RSS Projection runner；Inventory 与 checkpoint 同事务提交。receipt 与投影完成是独立事实，进程退出后从原持久记录继续。journal、投影 generation 与 definition 由 inventory-postgres 唯一持有，读写侧及示例共享；投影状态通过 RSS 公共 receipt_status 查询取得。worker 失败在关键任务退出前输出 mdm_inventory_failure 和封闭 phase，不记录 provider 正文或凭据。

## 查询契约

管理员每次查询均通过现有 Identity 在线验证和产品设备范围授权：

~~~text
GET /api/v2/devices/{device}/inventory
GET /api/v1/devices/{device}/collection-runs/{run}?source=mdm.windows
~~~

统一资产详情由当前授权设备集合、当前来源事实和 Manual 属性在同一数据库快照中生成，返回类型化字段、原始来源证据和 lastKnown。字段无期限；响应与查询/Group 使用同一解析结果，详见 [统一资产指南](202609210000-2463-unified-assets.md)。

采集运行诊断仍使用 source 封闭枚举，服务器派生 channel；调用者指定 tenant、registration、epoch 均拒绝。run 查询仅在当前可信 Scope 中定位，包含真实 receipt 与 projected/pending/pending_receipt/not_applicable 状态。所有成功与拒绝均审计，审计失败返回 503。

## 验证边界

T1 覆盖字段累计、完整性、非法值、冲突及纯超时。真实 PG/mTLS T2 覆盖分片、精确重放、提交未知、吊销后的原报告恢复、跨租户读取拒绝、投影事务失败和重启。F01 保留其独立的 RSS 接缝测试，生产应用不依赖 examples。

候选构建与实际进程验收见 [Docker 候选 部署](../deployment/202609120000-2353-candidate-deployment.md)。这些证据不替代 Windows 真机 T3。

## #2463 当前资产接口

资产详情、字段、搜索、保存查询与 Group 类型化接线以 [统一资产指南](202609210000-2463-unified-assets.md) 为准。资产接口已一次性替换来源选择和旧字符串 DTO；来源在每个字段的证据中返回。采集运行诊断仍按其真实注册/来源关联。字段无有效期、TTL 或自动过期，旧部署需独立处理，安装器拒绝旧清单。
