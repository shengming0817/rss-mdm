# Enrollment 与审计操作

本指南覆盖 #2347 模型经 #2350/#2351 演进后的单实例管理员入口。Windows 协议、TLS 和签发配置见 [Windows 注册与管理](202609111146-2350-windows-enrollment-management.md)。嵌入的 Identity 组件每请求通过自有 PG 权威验证，产品资源权限从当前持久化快照计算；Identity 管理员不会自动获得 MDM 管理权限。

## 配置与权限

`access_database`、`runtime_database`、`identity.database` 和 `management.database` 连接同一数据库，分别使用各自最小角色与独立受保护密码文件。统一资产读取借用 management 事务；服务配置没有顶层 `database` 或独立 Inventory reader 池。[完整配置](../../fixtures/mdm-config.example.json) 的 `native_protocols` 为必填结构，按 windows/apple 成员是否存在装配监听，空对象为 Agent-only。旧顶层 windows 和显式 null 不接受。

规则显式授予 `enrollment` 或 `credentials`，并配对目标设备范围。注册创建、恢复、取消需要 enrollment；撤销需要独立的 credentials。两种许可不互相继承。主体坐标为规范 UUID instance/tenant/principal。

## 管理 API

使用组件原生登录会话、精确 Origin、`X-Identity-Request: 1`、`X-CSRF-Token`、`Content-Type: application/json`。每次操作生成非 nil UUID `Idempotency-Key`；同操作重试保留键和业务参数。JSON 使用 camelCase，未知字段拒绝。

| POST 路径（前缀 /api/v3） | JSON | 行为 |
| --- | --- | --- |
| /enrollments | {"deviceId":"device-1","password":"调用端生成的43字符口令","source":"mdm.windows"} | 为显式 `mdm.windows`、`mdm.apple` 或 `agent.builtin` source 创建 pending Enrollment，冻结该 channel 当前注册世代 |
| /enrollments/{id}/resume | {"password":"新的43字符口令"} | 原管理员重新授权并轮换口令、会话引用，恢复原操作 |
| /enrollments/{id}/cancel | {} | 取消未绑定 Enrollment |
| /devices/{device}/registrations/{registration}/revoke | {} | 原子撤销指定注册、凭据和来源授权 |

调用端用 `python3 hack/enrollment-password.py` 生成 32 个随机字节的无填充 Base64URL 口令（256 位），自行安全保存。数据库只保存包含域、tenant 和 device 的摘要，响应不回显明文。Windows UsernameToken 的 username 填 enrollmentId，password 填该口令；管理员 cookie/token 不传给设备，也不保存到 PG。

Enrollment 成功响应 HTTP 200，包含 operationId、enrollmentId、status、expiresAt、source 和可选 registrationId。pending 只代表授权创建；bound 才有已原子提交的凭据和绑定。管理员不输入 expected_generation。source 必填且绑定后不可改变；服务端不从旧请求或设备类型推断。旧 `/api/v1/enrollments`、`/api/v2/enrollments`、`/enrollment-grants`、`/registration-requests` 及旧撤销入口均已删除。

查询当前状态使用以下 GET API，同样逐请求在线验证 Identity、设备范围并保存查询审计；GET 不要求 CSRF 或幂等键：

| GET 路径（前缀 /api/v3） | 权限与响应 |
| --- | --- |
| /enrollments/{id} | 原管理员及当前 enrollment；返回 enrollmentId、当前 status、授权口令 expiresAt（Unix 秒）和可选 registrationId |
| /devices/{device}/registrations?after={uuid} | 当前 credentials，独立于 enrollment；返回 items，每项含 registrationId、enrollmentId、channel、generation、status；nextCursor 非空时作为下一页 after，每页最多 100 项 |

只读状态不返回秘密，也不重放创建时的 pending 回执。凭据管理员先查设备注册列表，再用 registrationId 撤销；撤销后列表显示 revoked。Enrollment 的 bound 只表示绑定事实，当前凭据状态以注册列表及管理准入为准。expiresAt 是授权期限，不保证会话、权限或世代仍允许恢复；实际 resume 会重新检查这些条件。

无效会话 401、无权 403、输入错误 400、同键异参数/错误归属或状态冲突 409；依赖和审计故障 503。`operation_unknown` 表示提交结果未知。`x-request-id` 用于诊断，`Idempotency-Key` 回显已解析操作身份。回执是历史操作结果，不能代替当前凭据有效性检查。

## 恢复与撤销

口令默认有效 300 秒，并依赖原管理员的当前在线会话。超时或响应丢失先重发同键请求，不能靠换操作键掩盖未知提交。需要延长授权、管理员重新登录或应用重启时，由原管理员使用新的 resume 操作键和新口令恢复；同一个 resume 请求重试仍保持其原键和口令。resume 不改变 Enrollment、CSR、签发操作 ID、issuer、配置身份或预期世代。

已绑定且证书和当前映射仍有效时，resume 只允许重新取得原结果，不重新签发。并发换代、已取消、已撤销、叶证书过期或旧迁移待办不能恢复。原口令在成功轮换后立即失效。已绑定设备走独立 revoke API，cancel 不承担凭据撤销。

## 事务、审计与安装

AccessStore 独占事务、幂等回执和成功审计。grant 是不可变授权来源；request 是 pending/bound/cancelled 的唯一 Enrollment 状态 owner。先保存不可变签发意图，再确定性签名，最后在同事务保存证书、I01 注册、回执和成功审计。签名已算出但绑定未提交的证书不能进入管理通道。

审计写失败回滚成功业务；拒绝、查询及重试独立保存 denied/failed/success/replay，提交不确定记录 unknown。审计不含口令、私钥、协议秘密或管理员 token。运行角色不能查询审计历史。`audit_failure` 运维事件保留 request_id、已知 operation_id、action、write_outcome、原因；运维 owner 按租户和 request_id 定位并恢复数据库或权限，不将日志当作持久业务审计。保留期、备份和告警接入仍由部署 owner 持有。

当前 #2437 仅支持全新实例安装与完整匹配重放，按[认证指南](202609091600-2343-mdm-identity.md)准备全部角色、实例/存储/租户配置，并由 mdm_owner 执行 migrate。历史产品 SQL 保持不可变；旧 ledger 不匹配时拒绝且保留数据，不执行旧 grant/request 转换或会话续接。旧审计保留原历史含义，回退只能停止新部署后恢复旧独立部署。

运行角色只有必要 SELECT/INSERT 和列级 UPDATE：request 的状态/口令版本/引用/期限、注册和凭据状态、来源 enabled、协议 nonce 和会话进度；签发意图、证书字节与 grant 不可更新，审计仅 INSERT。仅临时 management_sessions/messages 有 DELETE，并由限制性 RLS 强制会话已过期及同租户；有效会话、凭据和审计历史不可删除。启动检查精确角色、RLS 与授权集合，清理策略被放宽也拒绝启动。

## 验证

`make test` 运行 T1；`make t2` 自动生成临时 CA/CSR/配置，使用真实 TLS PG、签名和 HTTPS/mTLS 握手验证恢复、全新安装及不匹配拒绝、隔离、撤销和重放。`make t2-identity` 验证嵌入组件、本地认证与可选企业 SSO。提交受测源码后运行 `make ci`。固定 HEAD、依赖与实际结果保存在 PR；Windows T3 独立实施。

Apple 签发、resume 与通知恢复使用独立一次性 attempt，见 [Apple 指南](202609230000-2471-apple-management.md)。当前允许的前一版迁移和停写要求见 [Apple 升级](../deployment/202609230000-2471-apple-management.md)，取代历史全新安装限定。
