# Group 类型化规则与成员差分（N02 / #2380）

`rss-mdm-group` 提供纯 Rust 规则校验、预览、完整重算和集合差分。只消费调用方输入，
不读取 Inventory、Group repository、HTTP、系统时钟或设备通道。自有代码没有运行时依赖；
Cargo 仅依赖固定 RSS revision 的 `rss-request-context::TenantId` 与 `rss-contract::Timepoint`，不 re-export。
本包 `publish = false`，独立 Git 源码消费不表示 registry 发布。

## 调用顺序

通过 `Criteria::predicate/and/or` 构造有界 AST，再用 `Rule::new` 一次校验字段字典、操作和类型。
Rule 拥有不可变字典和规则；版本字符串由调用方作为不可变输入的证据标识提供，不是解释器版本选择器。
字段键、单位和来源引用不允许空白或控制字符；字段值中的 Unicode/控制字符按普通字符串数据处理。
同一字典中字段键唯一，集合使用 `BTreeSet` 保留类型并规范去重。

调用 `Rule::evaluate(snapshot, as_of)` 预览一个或多个对象；`Rule::recalculate(snapshot, as_of, old)`
复用同一求值实现并返回差分。独立 `diff(tenant, old, new)` 不经 Criteria，供调用方比较静态或动态成员。
完整公共 API 示例和行为断言唯一位于 [consumer.rs](../../crates/group/tests/consumer.rs)，库入口还有可运行 rustdoc 示例。

字段类型为 String/Boolean/Integer/Time 及同类型 Set；每项 Field 包含 nullable、unit 和 operations。
事实的单位由绑定字典定义，操作数必须显式使用相同单位，不做单位转换或字符串到数值/时间的转换。
字典版本不匹配整体拒绝；字段和规则版本的唯一性及可信设备键映射由调用方承担。

| 字段类型 | 可选操作（仍须由字段显式允许） |
| --- | --- |
| 标量 | Eq / Ne / In / NotIn |
| Integer / Time | 另支持 Lt / Le / Gt / Ge |
| String | 另支持 Contains / NotContains |
| 同类型 Set | ContainsAny / ContainsAll |
| nullable 字段 | IsNull / IsNotNull（无操作数） |

字符串区分大小写，不做 Unicode 归一化；Contains 是字面子串，`%`、`_`、引号、反斜杠无语法含义。
空串是已知值；标量 In 空集合为假、NotIn 为真；已知集合 ContainsAny 空集合为假、ContainsAll 空集合为真。
空 AND/OR 拒绝。AND 遇 NoMatch 为 NoMatch，OR 遇 Match 为 Match，其余传播 Unknown。
所有分支都会先校验，解释保留所有叶子；不存在短路跳过非法输入的路径。

## 快照、未知与失败

Snapshot 绑定 tenant、候选集合完整性、字典版本、快照身份/版本及 coverage。
覆盖内每个对象都必须显式提供 Fact；缺值用 Missing 表示。事实没有单独的租户覆盖字段，
其归属只能来自所在 ObjectKey 的 tenant；ObjectKey 与 Snapshot、已有成员必须同租户。
对象重复仅在完整内容相同时接受，冲突拒绝。ObjectKey 排序使用完整 tenant 字节和对象标识。

调用方提供已解析的单字段事实（含 source、来源 snapshot_id、observed_at、可选 valid_until）；
核心不选择多来源优先级。有效窗为 `[observed_at, valid_until)`，没有 valid_until 表示调用方未设置失效时间。
未来事实为 Unknown(Future)，到达失效时间为 Unknown(Stale)，空或倒置有效区间拒绝。
Missing/Unsupported 保留各自原因；Null 只有显式 Null 操作可判定，普通比较为 Unknown(Null)。
包括负向及空集合操作在内，Unknown 不会自动转为匹配。

未知字段、非法类型/操作/单位、Denied、混租户、时间结构错误、预算超限整体报错，不返回部分结果。
Denied 表示调用方禁止消费该字段，不是核心执行过授权。未使用的输入字段也必须校验。
错误是封闭分类，不携带输入字符串；解释只含 AST 路径和结果，字段可经 `Rule::predicate_at` 定位。
来源信息在每个对象的 provenance 中按字段保存一次，结果还绑定规则/字典/快照版本及 as_of。

不完整候选集合或规则所需 coverage 不全时，重算整体拒绝；部分预览的未覆盖字段为 Unknown(Missing)。
完整性是调用方的事实声明，核心不能证明数据库是否漏行；N12 必须保证实际资产读取完整。
只有 Match 进入新集。**完整重算中旧成员变为 Unknown 时进入 removed，同时在 unknown 中列出**。
这遵循 N01，并不自行触发删除、撤销或持久提交；后续业务影响由组装负责。

差分为 new−old / old−new / 交集，分别输出 added/removed/unchanged，稳定排序去重。
相同输入重复求值结果一致；将新集作为下一轮旧集时 added/removed 为空。

## V1 预算

常量唯一位于包内 `limits`：深度 16（根为 1）、AST 节点 256、字段 128、每集合 256 项、
单字符串 4 KiB、字典和规则字符串合计 64 KiB、候选对象及每份成员列表各 10,000 项、
批次输入字符串合计 16 MiB、候选条数乘 AST 节点数不超过 1,000,000。
字符串按 UTF-8 字节计数；重复对象/成员仍计入输入预算，重算的旧成员与快照共用字节预算。
节点构造先限制深度/数量，错误树的校验和销毁不接受任意深度。超限报错，不截断成员或解释。

## 历史及上游来源

历史归档身份和恢复方法见 [reference](../../reference/README.md)。以下路径均相对于该历史快照：

| 来源 | 新测试中的对照与差异 |
| --- | --- |
| `src/internal/domain/group/value_object.go`、`rule_compiler.go`、`rule_compiler_test.go` | 嵌套 AND/OR 和字面条件结构；调用方自有字段名，不做旧字段转换 |
| `src/internal/domain/group/rule_engine.go` | 固定 as_of 代替 time.Now；稀疏快照不用空串/零值补齐 |
| `src/pkg/querybuilder/operator.go`、`builder.go`、`field_registry.go` | SQL ILIKE 与 expr contains 的大小写差异统一为精确字面匹配；数值/时间等号边界有对照 |
| `src/internal/domain/group/diff.go`、`diff_test.go` | 新增 unchanged、同租户去重和完整键排序 |

这些样本记录历史行为及明确改变的期望，不执行旧引擎，也不宣称旧实现通过了当前验证。
旧 Criteria JSON、expr/SQL、regex、daysAgo、组引用没有执行或转换入口，不保留兼容别名、缓存或双引擎。
当前 N12 实际接线字段仍限 `device.model`、`device.os.version`；其他类型的 fixture 不表示已交付采集能力。

Rust 操作分派参考 [evalexpr operator](https://github.com/ISibboI/evalexpr/blob/45e9634dab34328c8f2c6c675a50d4f654d79580/src/operator/mod.rs)。
本包直接实现受限类型化操作和三值事实语义，不依赖完整表达式解释器或移植其数值隐式转换。
