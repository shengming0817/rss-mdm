# RSS MDM

面向 Windows 与 macOS 的企业终端管理产品。服务端拥有设备身份、可信采集、统一资产、组/范围/策略、软件发布及管理 API；终端 Agent、Web 与 Identity 按独立产品边界协作。产品目标与实际支持矩阵分别以 PRD 和交付验收记录为准。
